# Code of Conduct

Martin Utils is a small hobby project. The bar is simple: be decent to each other.

## The short version

- Be respectful. Disagreements happen, insults don't need to.
- No harassment, hate speech, or personal attacks — in issues, PRs, discussions, or anywhere else related to this project.
- Assume good faith. Most misunderstandings are just that.
- Keep feedback about the code, not the person who wrote it.

## Scope

This applies to any space tied to the project: the GitHub repo (issues, PRs, discussions) and any Discord server where the bot itself is discussed on the maintainer's behalf.

## Enforcement

If someone's behavior crosses the line, report it by opening an issue tagged appropriately or contacting the maintainer directly (see [SECURITY.md](SECURITY.md) for contact info). Reports are handled case by case — expect anything from a warning to a ban from the repo, at the maintainer's discretion.
