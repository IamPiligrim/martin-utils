# Security Policy

Martin Utils is a small Discord bot, but if you find a security issue — a way to leak the bot token, escape a command's permission checks, cause a crash via crafted input (e.g. a malicious image for `/framethis`), or anything similar — please report it responsibly.

## Reporting a vulnerability

**Please don't open a public issue for security problems.**

Instead, report it privately:

- Open a [GitHub security advisory](https://github.com/IamPiligrim/martin-utils/security/advisories/new) for this repo, or
- Contact the maintainer ([@IamPiligrim](https://github.com/IamPiligrim)) directly.

Include:
- a description of the issue and its impact,
- steps to reproduce (a minimal example helps a lot),
- anything else that'd help pin it down (logs, stack traces, etc.).

## What to expect

This is a one-person hobby project, so response times aren't guaranteed, but reports are taken seriously and I'll do my best to acknowledge them and ship a fix in a reasonable time.

## Supported versions

Only the latest state of `main` is maintained — there are no versioned releases to patch separately.
